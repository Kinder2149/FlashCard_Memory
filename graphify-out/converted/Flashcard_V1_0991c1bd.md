## Sheet: Notice
| Flashcard — mode d'emploi du modèle |
| --- |
| Colonnes à remplir : Français (B), Anglais (C), Thème (D, optionnel). |
| Ne touche pas à la colonne ID (A) : elle est figée et sert d'identifiant à chaque carte. |
| La ligne EN-1 est un exemple : remplace-la par ta première carte, ou efface son contenu. |
| Ajouter un thème : va dans l'onglet « Themes » et ajoute-le dans la colonne A. |
| Il apparaîtra alors dans la liste déroulante de la colonne Thème. |
| Aller au-delà de 500 cartes : recopie le motif de la colonne A vers le bas (EN-501, EN-502, …). |
| Publier pour l'application (à faire une fois) : |
| Fichier → Partager → Publier sur le web → choisir l'onglet « EN » → format CSV. |
| Copie le lien fourni et colle-le dans l'écran d'import de l'application. |
| ⚠️ Ce n'est PAS l'URL de la barre d'adresse : il faut le lien de publication CSV. |
| L'application lit ce Sheet, elle n'écrit jamais dedans. Toute correction se fait ici. |
