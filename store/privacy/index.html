Politique de confidentialité — Flashcard Memory

Dernière mise à jour : 3 août 2026

Flashcard Memory est une application de révision de vocabulaire. Le respect de votre vie privée est une priorité.

Données collectées

L'application ne collecte, ne transmet et ne partage aucune donnée personnelle. Nous n'utilisons ni compte utilisateur, ni publicité, ni outil de suivi ou d'analyse.

Données stockées sur votre appareil

Vos cartes de vocabulaire, vos statistiques de révision et le lien de votre document sont enregistrés uniquement en local, sur votre appareil. Ces données ne quittent jamais votre téléphone et sont supprimées si vous désinstallez l'application ou videz la mémoire de l'app.

Accès à Internet

L'application accède à Internet dans un seul but : télécharger le document de vocabulaire (Google Sheet ou fichier) que vous fournissez vous-même via un lien. Ce document est récupéré directement depuis le service que vous avez choisi ; nous n'intervenons pas dans cet échange et n'en conservons aucune copie sur un serveur.

Fichiers locaux

Si vous importez un fichier Excel depuis votre appareil, il est lu ponctuellement pour en extraire le vocabulaire ; il n'est ni copié, ni conservé, ni envoyé.
